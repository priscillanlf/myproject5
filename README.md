# Dashboard de Veículos - Streamlit App

Este projeto é um aplicativo web desenvolvido com Streamlit para análise de dados de veículos usados.

## Funcionalidades

- Exibição de histograma do odômetro dos veículos
- Gráfico de dispersão entre odômetro e preço

## Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly Express
